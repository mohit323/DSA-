# Hashing

This folder contains my implementations and practice problems related to **Hashing**, a fundamental data structure technique used for efficient data storage, retrieval, and searching.

## 📚 Topics Covered

- Introduction to Hashing
- Hash Functions
- Hash Tables
- Collision Handling
  - Chaining
  - Linear Probing
  - Quadratic Probing
  - Double Hashing
- Open Addressing
- Load Factor
- Rehashing
- Searching, Insertion, and Deletion
- Frequency Counting
- Hash Maps and Hash Sets

## 💻 Implementations

The implementations are written in **C++** and focus on understanding the underlying logic, memory management, and time complexity of hashing techniques.

## ⏱️ Time Complexity

| Operation | Average Case | Worst Case |
|---|---|---|
| Search | O(1) | O(n) |
| Insertion | O(1) | O(n) |
| Deletion | O(1) | O(n) |

## 🎯 Objective

- Understand how hashing works internally.
- Implement different collision resolution techniques.
- Understand the trade-offs between different hashing methods.
- Solve DSA problems using hashing.
- Build a strong foundation for advanced data structures and algorithms.
