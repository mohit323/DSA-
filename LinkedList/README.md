## ⏱️ Time Complexity

| Operation | Singly Linked List |
|---|---|
| Access by index | O(n) |
| Search | O(n) |
| Insert at beginning | O(1) |
| Insert at end | O(n)* |
| Delete at beginning | O(1) |
| Delete at end | O(n) |

*Insertion at the end takes O(1) when a tail pointer is maintained.
